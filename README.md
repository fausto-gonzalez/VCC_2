# VCC_2

Repository for Assignment 2 of the **Version Control and Collaboration (VCC)** course at triOS College.

## Purpose

Practice using Git and GitHub to manage files, track issues, work with branches, review pull requests, and merge changes.

## Assignment Checklist

- [x] Create the repository and initial commit.
- [x] Create five files after the initial commit.
- [ ] Create five issues, including one bug report.
- [ ] Use a separate branch for each issue.
- [ ] Complete the changes and open pull requests.
- [ ] Review each pull request before merging.
- [ ] Resolve merge conflicts if necessary.
- [ ] Keep development branches on GitHub after merging.
- [ ] Optionally assign one issue to GitHub Copilot.

## Completion Requirements

- At least 12 commits.
- At least 6 branches.
- 5 closed issues.
- 5 closed pull requests.

## Verification

Run these commands in the terminal:

```bash
git log --oneline
git remote -v
```
